# 벡터 DB 수정 내용 (2026-11-24)

- **문제**: SQ8 인덱스의 최초 학습 데이터가 부족해 양자화 범위가 0으로 고정되고, 이후 벡터도 모두 같은 값으로 저장됨
- **조치**: `CELL 23`의 인덱스 생성부를 `faiss.IndexFlatIP(dimension)`으로 교체
- **저장 파일**: 기존 `article_vector.index` 이름과 경로는 그대로 사용하고 인덱스 형식만 FlatIP로 변경
- **백업 파일**: `article_vector.sq8_broken.index`는 기존 문제 상태 보존용이므로 운영 repository가 읽지 않도록 구분
- **검증**: 실제 최신 저장본에서 벡터 구분 능력과 검색 점수 분포가 복구된 것을 확인
- **추가 정리**: 해시·URL ID 혼용으로 생긴 중복 청크 8개와 본문이 `...`뿐인 빈 청크 1개를 정리한 별도 사본 생성. 공유 원본은 수정하지 않음
- **용량 판단**: 1024차원 float32 벡터 1만 개는 약 40 MB이므로 현재 규모에서는 양자화 이점보다 코드 단순성을 선택
- **참고**: 제네레이터 실행 시간은 별개 문제이므로 모델 생성량과 서버 상태를 따로 확인해야 함
