## 실제 실행 통과 항목

1. **모델 적재**: `vllm.utils.system_utils.logger`를 DEBUG로 설정한 뒤 L4에 생성 모델 적재 성공.
2. **네이버 API**: `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`의 작업본 접근 권한을 부여하고 실제 뉴스 검색·본문 수집 성공.
3. **벡터 DB 저장**: `SAVE_DIR` 자동 생성 후 FAISS 저장 오류 해소.
4. **복합 질문**: `젠슨 황이 엔비디아에서 퇴사하고 테슬라에 입사했다`를 두 주장으로 분리하고 각 주장의 기사·발행일·유사도 표시.
5. **복합 주장 답변 보정**: 최종 재실행에서 `엔비디아 퇴사는 확인 / 테슬라 입사는 근거 부족`으로 응답.
6. **단일 질문**: `컨닝 전문 조직이 있어?`를 한 주장으로 유지하고 실제 기사 3건 수집, RAG·일반 LLM 비교 및 출처 표시.
7. **최신 웹 재수집**: 같은 복합 질문 재실행에서 수집 단계를 다시 거치고 새 기사를 결과에 반영.
8. **결과 UI**: 완료 후 로딩을 숨기고 결과를 자동 표시하도록 수정한 뒤 정상 표시 확인.
9. **공개 실행 링크**: ngrok 토큰 없이 Colab 자체 프록시를 사용해 UI 접속 확인.
